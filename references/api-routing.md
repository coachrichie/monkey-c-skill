# Toybox API routing

Official source: https://developer.garmin.com/connect-iq/api-docs/

After synchronization, use:

- `.generated/api-docs/index.html` for Toybox module discovery.
- `.generated/api-docs/class_list.html` for modules, classes, enums, and typedefs.
- `.generated/api-docs/method_list.html` for method-name lookup.
- `.generated/api-docs/Toybox/` for direct symbol and text search.

For implementation decisions, retain documented API levels, supported products, permissions, deprecations, parameter constraints, return types, and thrown exceptions. If the separate `garmin-connect-iq` skill is installed, it can also provide the locally mirrored API reference.
