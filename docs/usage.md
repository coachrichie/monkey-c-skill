# Usage

Use the skill for Monkey C language questions, Core Topics questions, or Toybox API questions. Ask for the concrete concept and the target device/app context. The routing guides identify the relevant Garmin source family and the generated cache supplies local context when it is available.

Answers should cite the exact official Garmin page used. When a page is not cached, the skill falls back to the official source URL rather than inventing an offline citation.
