## Built with AI, for AI: a Monkey C skill for Garmin Connect IQ

What happens when you ask AI to build a developer skill—and make the build itself inspectable?

I started with a focused problem: make Monkey C, Core Topics, and Toybox API questions easier to answer with local, source-grounded context. The result is a public Codex skill for Garmin Connect IQ development.

The interesting part is the process. The owner selected the goals and source boundaries. AI helped turn them into tests, routing guides, synchronization tooling, installation scripts, diagrams, and documentation. Every generated reference remains a reproducible local cache; the public repository keeps the source links, contracts, and evidence visible.

The final showcase includes:

- local-first routing for Monkey C, Core Topics, and the Toybox API;
- deterministic synchronization and link validation;
- a safe installer for Codex;
- an AI-assisted case study with forward-validation scenarios; and
- a public CI workflow that checks the repository offline.

If you build with AI, the lesson is simple: let the model accelerate the work, but keep the goals, boundaries, and verification legible.
