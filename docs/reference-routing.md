# Reference routing

`SKILL.md` routes questions to three compact guides:

- `references/monkey-c-topics.md` for language syntax and semantics.
- `references/core-topics.md` for platform concepts and app behavior.
- `references/api-routing.md` for Toybox API lookup.

The synchronizer writes each approved source family below `references/.generated/`. A route first checks the matching local family, then falls back to the corresponding official Garmin URL. Local generated pages are cache material, not a replacement for Garmin's documentation.
