# AI workflow

The workflow is a small loop:

1. The owner selects the user problem, source families, and publication boundary.
2. AI turns those goals into failing contracts and a scoped implementation plan.
3. The repository gains one narrow capability at a time: routing, synchronization, installation, and showcase documentation.
4. Offline fixtures and live source checks provide evidence.
5. The resulting files explain both how to use the skill and how it was made.

This keeps prompts, decisions, and verification inspectable without pretending that generated text is authoritative. Garmin's pages remain the authority for API semantics.
